# Community conduct

We welcome contributors regardless of background or experience. Be respectful, focus feedback on the work, credit others' contributions, and assume good intent while accepting corrections.

Harassment, threats, discriminatory language, personal attacks, doxxing and publishing private information without permission are not acceptable in project spaces. Do not use issues or pull requests to target individuals.

Maintainers may edit or remove abusive content, close disruptive discussions, or restrict participation. Decisions should be proportional to the behavior and consistent across contributors. Report concerns to the repository maintainers; if private contact is needed, request a private channel without posting sensitive details publicly. Maintainers should treat reports confidentially where possible and avoid retaliation against reporters.
